# 🚲 Estudo de Caso - Divvy Bike-Share
### Análise Comportamental, Modelagem de Dados & Oportunidades de Conversão

> Projeto focado em analisar dados históricos da Divvy para identificar diferenças de comportamento entre usuários casuais e membros anuais, e propor estratégias de conversão.

**Autora:** Steicy Eduarda | Analista de Dados Jr.
**Stack:** SQL, Python, Power BI, Excel

### 📌 O que foi feito
- Limpeza e tratamento de +500k linhas de dados
- Análise exploratória do padrão de uso
- Segmentação de perfil: casual vs. member
- Insights para time de marketing
